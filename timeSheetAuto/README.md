# Fieldglass Time Sheet Automation

This project automates time sheet entry for Fieldglass using Playwright.

## Setup

1. Ensure you have Node.js installed.
2. Install dependencies: `npm install`
3. Set your credentials in `.env` file:
   ```
   USERNAME=your_username
   PASSWORD=your_password
   ```

## Running the Automation

- Using the batch file: Double-click `run-automation.bat`
- Using npm: `npm start`
- Directly: `node main.js`

## Output

Results are saved in the `test-results/` folder.
